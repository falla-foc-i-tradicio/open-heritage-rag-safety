# Data governance for demos and evaluation

The public project must use one of these classes of material only:

1. Synthetic material written for the project.
2. Public-domain material whose status has been checked for the relevant jurisdiction.
3. Material covered by an explicit written license or permission compatible with publication and machine processing.

It must never include membership lists, finances, bank movements, email exports, minutes, private photographs, access tokens, identifiers, or archive material merely because it is readable by the association.

For any later cultural-heritage benchmark, maintain a source manifest with rights basis, provenance, language, and removal contact.
