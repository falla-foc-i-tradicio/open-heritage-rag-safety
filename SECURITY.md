# Security policy

Please do not disclose private or personal data in a public issue.

For a potential vulnerability in this repository, contact the maintainers through the association's public website and include:

- a concise description of the issue;
- a reproducible, non-destructive demonstration;
- the affected version; and
- a safe contact address for follow-up.

This experimental library does not process production association data. Security reports concerning FallaERP or association systems must not be filed in this repository.
